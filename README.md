# 🌊 WalletWave

A full-stack **MERN expense tracker** that helps users manage income, expenses, transactions, and personal financial activity.

## ✨ Features

* 🔐 User signup, login & logout
* 💰 Add, edit & delete transactions
* 📊 Dashboard with balance, income & expenses
* 📅 Weekly and monthly spending overview
* 👤 User profile management
* 🔒 JWT authentication & protected routes
* 📱 Responsive dark-themed UI

## 🛠️ Tech Stack

**Frontend:** React, Vite, Tailwind CSS, React Router, Axios, Lucide React

**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, bcryptjs

**Tools:** Git, GitHub, Postman, VS Code

## 🚀 Run Locally

### Clone

```bash
git clone https://github.com/harsh-sachan2244/WalletWave.git
cd WalletWave
```

### Backend

```bash
cd backend
npm install
npm run dev
```

Create `backend/.env`:

```env
PORT=8000
MONGODB_URL=your_mongodb_url
JWT_SECRET=your_jwt_secret
NODE_ENV=development
```

### Frontend

Open a new terminal:

```bash
cd frontend
npm install
npm run dev
```

Frontend: `http://localhost:5173`

Backend: `http://localhost:8000`
